# 用户指南

## 打开书库

启动时，Zephyr 会尝试打开上次使用的书库文件夹。如果文件夹不可用，会进入应用支持目录中的临时书库，便于继续启动。要使用已有的纯纯写作书库，请选择包含 `App/Room.db` 的**书库根文件夹**；不要直接选择数据库文件。界面显示“临时书库”时，请选择正式书库文件夹。

书库按书籍和章节组织。侧栏可切换书库、书籍和章节；窄屏设备用左侧抽屉访问书库。章节支持搜索、排序以及历史记录。编辑区提供选择、撤销与重做、字数统计、快捷工具栏和自定义键盘快捷键。

## 编辑与外观

打开章节后直接输入纯文本。Zephyr 会在书库中保存内容，并在切换章节、切换书库和备份前刷新待保存的编辑。设置中可调整字体、段落缩进、行距、页边距、背景、主题和快捷工具栏。桌面端和移动端使用相同书库数据，但导航布局会随窗口宽度改变。

## 备份与恢复

在设置的备份区域可创建本地 `.pwb` 备份、查看备份并恢复。恢复前请确认目标书库和恢复模式；覆盖恢复会替换目标内容。内容有变更时，开启自动备份会每小时创建一份本地备份；移动端进入后台时也会备份。自动备份保存在 `Backups/Auto/`，手动备份保存在 `Backups/`，两者合计保留最近 25 份 Zephyr 备份，不清理已有的纯纯写作备份。可在设置中输入坚果云账号、WebDAV 网址（默认 https://dav.jianguoyun.com/dav/）和第三方应用密码。云端数据存放在 WebDAV 根目录的 Zephyr/ 中，历史备份保留最近 25 份。桌面端退出时窗口立即关闭；若已开启本地自动备份或已连接坚果云，独立后台进程会完成本地/云端备份（云端仅上传、不拉取合并），完成后用系统通知报告结果；移动端继续在进入后台时同步。可手动上传、同步和恢复云端 .pwb 备份；本地编辑不依赖连接。当前只使用一个本地目录，可从文库菜单重新选择；如果所选目录与云端书库 ID 不同，云操作会停止并提示，原云端数据不会被覆盖。旧版 PureWriter/<书库 ID>/ 路径下的云文件不会自动迁移或删除。

## 安全使用已有书库

- 首次接入重要书库时，先保留一份独立备份。
- 不要让纯纯写作和 Zephyr 同时写入同一个 `App/Room.db`。
- 未识别的 Room schema 会只读打开；不要绕过此保护或手工修改数据库版本号。
- 临时书库位于应用支持目录，选择正式书库前不要把它当作长期备份。
