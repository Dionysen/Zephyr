# 用户指南

## 打开书库

启动时，Zephyr 会尝试打开上次使用的书库文件夹。如果文件夹不可用，会进入应用支持目录中的临时书库，便于继续启动。要使用已有的纯纯写作书库，请选择包含 `App/Room.db` 的**书库根文件夹**；不要直接选择数据库文件。界面显示“临时书库”时，请选择正式书库文件夹。

书库按书籍和章节组织。侧栏可切换书库、书籍和章节；窄屏设备用左侧抽屉访问书库。章节支持搜索、排序以及历史记录。编辑区提供选择、撤销与重做、字数统计、快捷工具栏和自定义键盘快捷键。

## 编辑与外观

移动端快捷输入栏首次使用时默认包含“”、‘’、顿号、（）、《》、⌈⌋、——、……。较长的破折号和省略号在按钮上分别显示为“—”和“…”；点按仍插入完整标点。快捷栏可左右滚动，拖到边界时有弹性动画。点按‘’或⌈⌋会将光标放在成对标点之间，输入内容时显示胶囊高亮；按回车可跳到右侧标点之后。可在快捷输入栏的工具面板中编辑、删除或调整这些默认项，已保存的个人布局不会因默认项更新而被重置。

打开章节后直接输入纯文本。移动端点击正文放置光标后，可拖动光标下方的手柄精确调整位置；输入、滚动或切换焦点时手柄会收起。Zephyr 会在书库中保存内容，并在切换章节、切换书库和备份前刷新待保存的编辑。设置中可调整字体、段落缩进、行距、页边距、背景、主题和快捷工具栏。桌面端和移动端使用相同书库数据，但导航布局会随窗口宽度改变。

## 备份与恢复

在设置的备份区域可创建本地 `.pwb` 备份、查看备份并恢复。恢复前请确认目标书库和恢复模式；覆盖恢复会替换目标内容。内容有变更时，开启自动备份会每小时创建一份本地备份；移动端离开应用（返回退出、按 Home/多任务切走，或进程被结束后由已排队任务继续）时，有未备份改动会经系统后台任务自动备份；若同时开启云备份并已绑定坚果云，会在后台上传。进行中仅显示「正在备份」通知，完成后自动消失，不再提示成功。桌面端关闭窗口时会等待本地及云端备份完成；失败时窗口重新显示，允许重试。首次在 Android 13+ 上可能会请求通知权限。自动备份保存在 `Backups/Auto/`，手动备份保存在 `Backups/`，两者合计保留最近 25 份 Zephyr 备份，不清理已有的纯纯写作备份。云同步需先开启「开启云备份」，再绑定坚果云（账号、WebDAV 网址默认 https://dav.jianguoyun.com/dav/、第三方应用密码）。云端是本地备份的异地副本，数据在 WebDAV 根目录的 Zephyr/ 中（`library.pwb`、历史备份、以及桌面/移动各自一份偏好：`settings-desktop.json` / `settings-mobile.json`；书库章节两端共用，主题与侧栏布局等按端分离），历史备份保留最近 25 份。新机可先选择空目录并绑定同一坚果云账号，再从云备份恢复：空库会认领云端书库并恢复章节与本端设置；坚果云密码仍需在新机填写。桌面端退出时先打一份本地备份；若已开启云备份并完成绑定，再将该文件与设置上传到云端，并在当前进程中等待完成（失败则窗口重新显示以便重试）。可在「坚果云设置」中查看或修改凭据。当前只使用一个本地目录，可从文库菜单重新选择；若本地已有正文且与云端书库 ID 不同，云操作会停止并提示，原云端数据不会被覆盖。旧版 PureWriter/<书库 ID>/ 路径下的云文件不会自动迁移或删除。

## 安全使用已有书库

- 首次接入重要书库时，先保留一份独立备份。
- 不要让纯纯写作和 Zephyr 同时写入同一个 `App/Room.db`。
- 未识别的 Room schema 会只读打开；不要绕过此保护或手工修改数据库版本号。
- 临时书库位于应用支持目录，选择正式书库前不要把它当作长期备份。

## 保存与退出

编辑时，每次正文或标题变化都会立即排入本地恢复草稿写入；正文与标题仍会在短暂停顿后写入 `App/Room.db`。切换章节、创建备份和正常退出都会等待这些写入完成。若写入失败，编辑器会提示并保留待保存内容，正常退出和备份不会将未保存内容视作成功。

已开启云备份时，桌面关闭窗口及移动端主动返回退出会等待云端上传完成；上传失败会留在编辑器以便重试。移动端按 Home、切换应用或被系统终止无法等待网络上传，Android 会安排后台任务重试；此时“正在备份”不代表云端已完成。选择合并恢复时，若相同时间戳对应不同正文，会保留本地正文，并将另一版本放入该章节的“时光机”。
